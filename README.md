## Description

This sketch creates a reflective, meditative camera experience that scrolls through a world larger than the screen.

The camera follows an authored path using easing, pause-based pacing, and subtle drift to evoke a calm, breathing rhythm. Small discoverable symbols appear only when in view, encouraging quiet observation rather than goal-driven gameplay.

---

## Interactive Instructions

The camera moves automatically.

Click on visible symbols to quietly discover them.

Press D to toggle the debug overlay.

When all symbols are discovered, the counter disappears and the experience continues.
